# HFT Project: Moving Average Crossover Strategy

This project is a simple yet impressive High-Frequency Trading (HFT) system demonstrating a hybrid C++/Python approach. The performance-critical backtesting engine is written in C++, while data generation, analysis, and visualization are handled in Python.

## Project Structure

- `cpp_core/`: Contains the C++ backtesting engine.
- `python_analysis/`: Contains Python scripts for data generation and analysis.
- `data/`: Stores the generated market data.
- `build/`: (Generated by CMake) Contains the compiled C++ code.

## Core Logic

- **Strategy**: A moving average crossover strategy.
  - **Buy Signal**: Short-term moving average crosses above the long-term moving average.
  - **Sell Signal**: Short-term moving average crosses below the long-term moving average.
- **Engine**: The C++ core processes market data ticks and applies the strategy efficiently.
- **Integration**: `pybind11` is used to create Python bindings for the C++ engine, allowing it to be controlled from a Python script.

## Prerequisites

- A C++17 compliant compiler (GCC, Clang, MSVC)
- CMake (version 3.12 or higher)
- Python (version 3.8 or higher)
- `pip` for installing Python packages
